# ADR-001: Use Prisma for Database Access

## Status: Accepted

## Context
The team evaluated Prisma, Drizzle, and raw SQL for database access.

## Decision
Use Prisma ORM for all database queries.

## Rationale
- Team has more Prisma experience
- Migration system fits our deployment pipeline
- Type safety with generated Prisma Client

## Consequences
- No raw SQL anywhere in the codebase
- Prisma schema is the source of truth for data models
- Migration files must not be manually edited
